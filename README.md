
# Employee Management System (EMS)

A production-style Employee Management System built using Java Spring Boot, React, and MySQL.

## Project Information

- Project ID: EMS-2026-001
- Architecture: Modular Monolith
- Backend: Java 21, Spring Boot
- Frontend: React
- Database: MySQL
- Build Tool: Maven

## Project Overview

The Employee Management System is designed to simplify employee administration and HR operations.

It provides role-based access for administrators, HR personnel, managers, and employees.

## Core Modules

1. Authentication and Authorization
2. Employee Management
3. Department Management
4. Attendance Management
5. Leave Management
6. Dashboard
7. Audit Logging

## User Roles

- ADMIN
- HR
- MANAGER
- EMPLOYEE
